whatmodel.sh helps you find AI models you can actually use: on your own machine, on a server, or through an API.

Choose your RAM, GPU and budget to compare language, image, video and speech models. Each model links to its benchmark sources and available run options. You can also [browse lists for common machines](/browse).

## Where the numbers come from

Scores combine reviewed benchmark results. Prices, memory requirements and download commands come from the sources linked on each model's page. Memory figures include estimates, and the catalogue is still incomplete.

The [methodology](/method) explains how scores are calculated, what uncertainty means and which sources are included. A high score is a useful starting point; try a model on your own tasks before choosing it.

## Built to be checked and improved

The data and scoring engine live in the [whatmodel repository](https://github.com/jakemanger/whatmodel). These pages are Markdown files in the same repository. Use the edit button to suggest a correction through a pull request.

See [how to contribute](/contribute) for data fixes, new models and documentation changes, or read the [FAQ](/faq).
