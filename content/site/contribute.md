## Edit an information page

1. Press **edit this page on GitHub** on the About, FAQ or Contribute page.
2. Sign in to GitHub and edit the Markdown text. GitHub can guide you through creating a fork if needed.
3. Propose your change and open a pull request with a short explanation.

Changes are reviewed before they appear on the site. No local development setup is needed for a text edit. The files live in [content/site](https://github.com/jakemanger/whatmodel/tree/main/content/site).

## Correct data or add a model

Follow the repository's [contribution guide](https://github.com/jakemanger/whatmodel/blob/main/CONTRIBUTING.md) and [data updating guide](https://github.com/jakemanger/whatmodel/blob/main/UPDATING.md). Include a source link for each number and use an allowed source.

If you would rather report a problem, [open an issue](https://github.com/jakemanger/whatmodel/issues/new/choose) with the model name, the incorrect or missing information and a supporting source.

## Share a speed measurement

The [benchmark page](/bench) explains how to measure a model on your machine and prepare a result for review.

## Improve the scoring or code

For changes to how scores are calculated, start a discussion in the repository so the approach can be reviewed before implementation. The [methodology](/method) describes the current calculation and its limitations.
