## Rules applied
- Only rows that show one harness per run were taken. For example, GameLogicBench takes only the Claude Code rows and SWE Atlas only the mini-SWE-agent rows. Video2World takes only the OpenCode rows.
- Rows were dropped when the identity was ambiguous:
  - GPT-4o with no snapshot
  - Qwen3-VL with no Instruct/Thinking label
  - DeepSeek V4 where the paper does not say whether it ran the preview or the 0813/0731 release
  - undated Qwen3.8-Max after the 0902 snapshot existed
  - Rows dated before July 2026 map DeepSeek V4 Pro to the April preview.
- Rows that look like harness or format failures were dropped and the reason recorded in scope/gaps. Examples are an all-zero tool-calling row and VisEditBench's Gemini 3 Flash at 46% executability. Others are gpt-oss-120b at near chance in DiagnosticIQ and MiniMax-M2.5 at 0.19% in Thinkingbox.
- Each note gives the table, row label, column and printed value, the setting or reasoning effort, and how the checkpoint was mapped.
