# Research refresh — 21 October 2026

Reviewed all five categories against the 16 October snapshot (`46c9a6f`). This pass adds
18 model identities and 99 net result rows: 848 fresh or replacement observations replace
749 superseded observations, taking the catalogue to 1,942 models, 22,291 results and
997 benchmark definitions. Scores remain computed by the existing scoring engine.

## Sources and scope

- **Arena:** CC BY 4.0 publisher dataset at
  [`9041150e8a502da9f0e75c89824d34ad7dba7072`](https://huggingface.co/datasets/lmarena-ai/leaderboard-dataset/tree/9041150e8a502da9f0e75c89824d34ad7dba7072).
  Imported 774 observations: text 349, vision 137, web development 123, search 37,
  text-to-image 27, image editing 51 and agent IPS 50. Replaced the prior observation
  for each matched model/task, rather than averaging snapshots. Preserved 179 unchanged
  observations, including all three video splits and the document split. Exact model
  names, highest available reviewed effort, publication dates, votes and intervals are
  in each result note. Ambiguous aliases and unverified checkpoints remain excluded.
  IPS retains its signed original units. This is the licensed dataset, not a website scrape.
- **Epoch:** [internal benchmark archive](https://epoch.ai/data/benchmark_data.zip),
  SHA-256 `d028f2aa787630655329063db9b535aae48641cb5626b27e7bf7aad61aaffd40`.
  Added Mistral Large 4 high on chess (0.33); replaced GPT-6 Astra max with its newer
  promax chess run (0.76). The 15 October Muse Wonder furniture result was already present.
  Only ledger-approved internal CSV members were used; external and aggregate rows were excluded.
- **Maker reports:** 62 individual LLM results from final Beam, DeepSeek 1017, NVIDIA
  Super VL/Bolt and Liquid model cards. Beam's Apache-2.0 and DeepSeek's MIT repository
  licences were read and preserved. NVIDIA and Liquid figures were hand-recorded solely
  for the maker's own models under the owner's 7 October vendor-facts policy, on existing
  benchmark IDs. No competitor columns, Artificial Analysis scores or ambiguous protocol
  matches were imported. DeepSeek's same-maker September comparator is an original run
  in its newly licensed report, not a copied third-party row.
- **Speech:** original author results from the Apache-2.0 Aurora and Cactus cards and
  CC BY 4.0 Fermion card; copied comparator figures were excluded. The
  [Drama 3 report](https://arxiv.org/html/2610.18010v1) explicitly carries CC BY 4.0.
  Its new runs for Drama 3, Eleven v4 and Inworld TTS-2 supply a derived, unweighted
  24-language mean error. All three have all 24 language rows. Soniox's missing Cantonese
  result and the report's copied OmniVoice/FireRed/S2 rows were excluded. Inworld's
  [official model list](https://docs.inworld.ai/tts/tts-models) and hosted endpoint identify
  TTS-2 as `inworld-tts-2`; its [release history](https://docs.inworld.ai/release-notes/tts)
  also corrects the catalogue's release month from August to May 2026.

## Prices, run routes and unchanged sources

Six new priced API routes: DeepSeek Flash 1017, MiniMax M3.1 Flash, and all four Voxtral 3
variants. The DeepSeek route explicitly states off-peak $0.15/$0.60 per million
input/output tokens and the doubled peak rates. Its old Flash aliases now serve 1017,
so the September checkpoint loses that direct API route while retaining its weights
and historical measurements. Existing third-party endpoints are not silently reassigned.
Unknown prices stay unknown. Runtime commands were documentation-reviewed, not executed;
new local memory figures are explicitly estimates.

Checked the current licensed Open ASR CSVs, carun TTS REPORT_DATA, EQ-Bench 3, Pipecat,
llama.cpp and mlx-lm benchmark documents. No new compatible measurements were imported
from these sources. The current models.dev direct-provider prices were compared with
the corresponding existing numeric catalogue entries; no changed prices were found in
that matched set. Aggregator routes and OpenRouter-derived rows were excluded.
No new local-speed or API-throughput measurement was verified with the exact hardware,
runtime and workload needed for this catalogue. Existing measurements and disabled speed
calibration remain unchanged.

Held back: mismatched benchmark versions, restricted third-party metrics, prelaunch Beam
numbers, MOSS pretraining/layout results whose final SFT checkpoint could not be established,
Voxtral's incompatible FLEURS subsets, unverified memory requirements, and duplicate
video quantizations/editions. New models without usable measurements remain unscored;
this pass does not manufacture scores to fill gaps.

The LLM check samples 300 cells; added/replaced observations change which cells are sampled,
so the correlation increase is not evidence of improved predictive accuracy. Its accuracy
median/p90 error changes from 3.3/12.4 to 3.8/15.5 percentage points; Elo from 30.6/74.3
to 22.6/121.5. Four sampled linear observations report median raw error 0.2919 before and
14.7054 after; the different samples mix benchmark-specific units, so that pooled statistic
is not a matched comparison or a percentage error. Raw values and their defined transforms
were retained; no scoring formula or scale was changed.

Image and TTS diagnostics remain weak, as before this update. Excluding floor-weight series,
image correlation is 0.594 both before/after; TTS changes from 0.422 to 0.404. These limitations
and sparse/disconnected comparisons are not repaired by adding a model or inflating the row
count. The full catalogue now has 1,893 scored models and 49 awaiting sufficient evidence;
separate comparison sets cannot be ranked against the main scale.

Other local checks passed: 124 Node tests, 21 Python bench tests, data-package typecheck,
website type generation and TypeScript check, ESLint, feed-specific evidence/history tests,
and the complete production compile-mode build. After the final documentation/runtime
