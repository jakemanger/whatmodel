## Owner flags (imported, but worth a look)
- **Seed2.0 Pro is mapped to `dola-seed-2-0-pro`.** The name matches, and Dola is ByteDance's app brand, but no document ties the two. A separate entry would have formed an isolated two-model comparison set. Seed2.0 Lite is a new model.
- **The GPT-4.1-table CharXiv-R cells are probably python-enabled.** OpenAI's GPT-5 developer post labels the identical figures that way. They are filed under `charxiv-rq` because vendor rows may only use existing ids, and the setting is in each note.
- **Some OpenAI τ²-telecom figures use a modified prompt.** GPT-5.1, GPT-5.2, GPT-5.4 mini and GPT-5.4 nano went into OpenAI's `tau2-telecom` run with the prompt change stated in each note.
- **The AHELM ids are llm-category audio tests that belong to no task.** The owner may want an audio task, or to leave them in the overall LLM fit.
- **Several TriviaQA runs on the Hallucinations Leaderboard are very low.** Llama-2 and Orca-2 tqa8 score about 0.09, probably an answer-format problem. They are kept as valid because they are not below the random baseline and are not flagged, and each note says so.
- **The Olmo-3-7B-Think card swaps two OMEGA cells against report v2.** The card prints SFT 45.0 / final 37.8; the report prints 37.8 / 45.0. The existing `olmo-3-7b-think` omega row follows the pinned card. No change was made.
